# NEXUS AI — 404 ERROR
A small browser-based frontend starter for the wHACKiest Track 1 prototype.

## Run
Open `prototype/index.html` in Chrome or Edge. No installation is needed.

## Important demo limitations
This is a frontend proof-of-concept. The workflow planner and approval are simulated.
Meeting extraction uses simple browser-side keyword heuristics.
There is currently no real MCP client/server, external AI model, calendar access,
email access, live meeting attendance, or external action execution. Do not claim
those features are implemented until they are connected and tested.
